Stellar reference

The background uses 1,018 catalog stars to magnitude 4.6, with bright-star names and constellation lines adapted from SatObserver-MX’s d3-celestial / BSC5 / HYG catalog. RA/Dec grid spacing is 2 hours and 30°. The stellar sphere is at infinity: camera panning does not create false stellar parallax.

Catalog coordinates are rounded J2000 equatorial directions with no proper-motion correction. This is an orientation reference, not a precision observing chart. The scene uses an external camera; geometric geocentric RA/Dec readouts are computed independently from the Earth-to-MMX vector.
